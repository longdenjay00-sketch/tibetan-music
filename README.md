# Tibetan music vault

A local study vault for Tibetan music: history, culture, scales, instruments, ritual sound, and the acoustics behind them.

Open this folder as a vault in Obsidian. Start at [[Home]].

The notes were written on 2026-11-13 from published ethnomusicology, monastery teaching accounts, and institute pages. Full citations are in [[Sources]]. Romanization varies. Where scholars disagree, the note says so.

This vault does not replace a teacher. Chant lines, fretless fingerings, and ritual roles are transmitted in person. The scale tables are a map of Central Tibetan specialist practice, not a rule for every valley.
